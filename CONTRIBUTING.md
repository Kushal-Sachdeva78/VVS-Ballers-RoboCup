# Contributing

This repository documents the VVS Ballers RoboCupJunior Soccer (IR League) robots across seasons:
firmware (C++), KiCad boards, Fusion 360 CAD, photos and the Team Description Paper materials. It is an
archive of the robots as built.

## How to engage

- **Corrections and problems** — open an issue naming the file and what is wrong (a wrong pin, a typo,
  a broken link, a missing photo).
- **Pull requests** — documentation fixes and clearer build notes are welcome. For changes to the
  firmware, the boards or the CAD files, open an issue first, since the repository records the robots as
  they competed. The repository is already large (about 130 MB), so please ask before adding video or CAD exports.
- **Response time** — I aim to reply to every new issue within 24 hours
  (India Standard Time). If I'm slower than that, I'll say so on the issue
  rather than leave it silent.

## Code of conduct

Be respectful and constructive. This is a student project; good-faith questions
and careful, well-documented contributions are appreciated.
